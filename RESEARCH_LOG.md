## Uniform supplemental quote valuation (fixed before new prices)

- Scope: every originally executed IS portfolio position, all three original option legs, every regular session from entry through fixed exit inclusive. No favorable-gap-only replacement, contract reselection, restored skipped signals or parameter winner.
- Retrieve the latest quote state in the same regular NYSE session strictly before its actual cash-session close, using SIP timestamp; take highest sequence number for timestamp ties. Request descending records and validate ordering/bounds. If the tie at the response limit cannot be resolved, mark unavailable.
- Validate the latest state, never search backward for an older valid state. Require finite bid >= 0, ask > 0, ask >= bid, positive bid/ask sizes and known integer SIP timestamps. Explicit invalid/unknown conditions cannot be silently certified. Provider condition metadata absence is a disclosed limitation.
- Primary diagnostic: every leg no more than 60 seconds old, and inter-leg timestamp range no more than 60 seconds. No spread-based favorable selection. A prespecified 300-second age sensitivity, with the same 60-second synchronization constraint, is reported separately; it cannot replace the primary because its result is better.
- Use midpoints solely for supplemental mark-to-market; also report bid/ask spread/side-cost diagnostics. These are indicative snapshots, not guaranteed synchronous fills. If any required leg fails, NAV remains unavailable; no interpolation or deletion of days. The query spans the same session so a standing quote with no recent update is assessed by its age, not falsely called no access.
- Preserve original cashflows, entry/exit dates, position counts, drawdown decisions and skipped signals. Supplemental NAV = original cash + mark of the original open ledger. Closing cashflows remain original executions/proxies. This is valuation sensitivity of a frozen legacy ledger, not a quote-reexecuted strategy or repaired admission path. Identify the mixed original cashflow/supplemental-mark convention prominently.
- Verify contract metadata as-of entry and exit for all original three legs: multiplier, type, strike, expiry, underlying and additional deliverables. Query splits/dividends only within IS holding intervals. An unresolved deliverable/action is not silently assumed standard. Dividends/assignment remain relevant limitations of synthetic parity, even when metadata are standard.
- Preserve quote request manifest, source timestamp, provider status, retry counts and coverage. Cache licensed quote inputs privately; public reports contain aggregate/derived evidence only. Credentials load into the authenticating process and are never output.
